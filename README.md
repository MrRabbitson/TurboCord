# TurboCord
API Discord для TurboWarp

Сделан MrRabbitson

## Установка
1. Зайдите на https://github.com/MrRabbitson/TurboCord/blob/main/TurboCord-rus.js
2. Скопируйте текст из файла
3. Зайдите на https://turbowarp.org/
4. Добавьте пользовательское расширение
5. Выберите "ТЕКСТ" (см. скриншот)


    ![Скриншот 1](https://github.com/user-attachments/assets/c9de7eff-e654-47b6-acae-88da05c1e536)
6. Поставьте галочку на "Запустить без песочницы

    ![Скриншот 2](https://github.com/user-attachments/assets/ed3367f8-7d14-40ca-b968-f33a794ae394)
7. Вставьте ранее скопированный текст в поле

   ![Скриншот 3](https://github.com/user-attachments/assets/9bef6be3-4585-4f8f-8f93-1df263d1c1bb)
8. Нажмите "Загрузить"
